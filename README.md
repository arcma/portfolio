## Run Locally

This is a static website. No backend server or package installation is required for basic local viewing.

1. Clone or download this repository.
2. Open `index.html` in a web browser.

For a more consistent local development experience, serve the project directory with any static web server, such as the VS Code Live Server extension.

## Project Structure

```text
.
├── index.html
├── index2.html
└── assets/
    ├── css/
    ├── js/
    ├── fonts/
    ├── images/
    └── lib/
```

- `index.html` / `index2.html` — Portfolio page entry files.
- `assets/css/` — Compiled stylesheets.
- `assets/js/` — Portfolio JavaScript.
- `assets/images/` — Backgrounds, banners, and project images.
- `assets/fonts/` — Local font files.
- `assets/lib/` — Third-party CSS, JavaScript, and related library assets.
